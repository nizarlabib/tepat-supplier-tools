
# Project Instructions

## Tech Stack
- React with TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Motion for animations when needed

## Architecture
- Use reusable components.
- Keep each landing page section separated.
- Avoid oversized components.
- Separate static content into data files.
- Use semantic HTML.

## Design Guidelines
- Prioritize premium and modern aesthetics.
- Avoid generic template-looking designs.
- Use consistent typography and spacing.
- Make every section responsive.
- Use appropriate images and visual hierarchy.
- Avoid excessive gradients and animations.

## Code Quality
- Avoid unnecessary dependencies.
- Avoid using `any`.
- Keep TypeScript types explicit.
- Remove unused imports.
- Ensure responsive behavior.
- Run lint and production build.

## Workflow
- Read the existing project before modifying it.
- Create an issue.md before implementing major changes.
- Work incrementally.
- Do not modify unrelated components.
- Verify the production build after changes.
